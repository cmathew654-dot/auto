# How it started

Before writing the tool, I made a tiny one-page interview for planners. I wanted a rough picture of how often holdings entry came up, how long it took, and where the rework happened.

The original page was made quickly and was not retained. The public page in this repository is a reconstruction from memory, not the original interview and not a record of anyone’s answers.

The questions were deliberately ordinary:

- How many plans do you release in a typical week?
- How many of those plans require holdings to be entered?
- About how many positions are in a typical account?
- How long does holdings entry take per plan?
- What format does the holdings information usually arrive in?
- Where do mistakes or rework tend to happen?
- If one part could be faster, which part would you choose?

The page opened a prefilled email in the respondent’s mail app. It had no database or submission endpoint. The answers pointed toward the same narrow problem: review the file first, make blocked rows visible, prepare only the fields that should be entered, and keep the final save with the operator.
